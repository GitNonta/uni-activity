🔁 Uni-Activity — Student Registration Sequence

โฟลว์หน้าจอจริงสำหรับนักศึกษา: ดูรายการกิจกรรม → ดูรายละเอียด → กดลงทะเบียนขณะยังไม่ Login → Login + OTP → ลงทะเบียนสำเร็จ → รออนุมัติ

100%student-sequence-diagram.mmd → student-sequence-diagram.svg

🎯 โฟลว์หลัก

  • ① Public: `/` → `/activities`
  • ② เลือกรายการ → `/activities/{id}`
  • ③ กด Register ขณะ logged out → `/login`
  • ④ Login สำเร็จ → OTP → กลับหน้ากิจกรรม
  • ⑤ POST register → `pending` → Admin approve

📱 หน้าจอที่เกี่ยวข้อง

  • activities/index.blade.php — รายการกิจกรรม
  • activities/show.blade.php — รายละเอียด + ปุ่มลงทะเบียน
  • auth/login.blade.php — Login
  • auth/verify-login-otp.blade.php — OTP
  • /my-activities — สถานะหลังลงทะเบียน
